🚀 Base URL

Pastikan server PHP Anda berjalan dengan menjalankan perintah php -S localhost:8000

http://localhost:8000
GET

/produk

💡 Bro, ini cara pakenya:
GET itu ibarat lo minta katalog atau nanya "Eh, ada barang apa aja nih?". Metode ini cuma buat mengambil atau membaca data. Kalo lo ketik sesuatu di kolom pencarian, dia bakal nyariin barang yang namanya mirip-mirip.
http://localhost:8000/produk?search=
POST

/produk

💡 Bro, ini cara pakenya:
Kalo POST ini lo bayangin kayak "ngirim paket" ke gudang buat nambahin barang baru! Lo harus masukin data barang (kayak nama, harga, stok) di dalam kotak Body (JSON) di bawah, terus klik Try it out buat nyimpen ke database.

Body (JSON):

PUT

/produk/{id}

💡 Bro, ini cara pakenya:
Nah, PUT ini dipake khusus buat ngedit atau update barang yang udah ada. Wajib banget lo masukin nomor ID barang di ujung URL-nya, terus tulis data yang mau diubah di kotak Body (JSON). Data lama bakal ditiban sama data baru ini.
http://localhost:8000/produk/

Body (JSON):

DELETE

/produk/{id}

💡 Bro, ini cara pakenya:
Sesuai namanya, DELETE ini buat nge-hapus barang! Hati-hati ya pakenya. Gampang banget, lo tinggal masukin angka ID barang yang mau dihilangin di ujung URL. Sekali klik Try it out, barang langsung musnah dari sistem!
http://localhost:8000/produk/
